Tudo o que dá para ajustar no Ghostty, no prompt do Starship, no zsh e nas ferramentas instaladas por src/modern-terminal.sh, com exemplos prontos para copiar. Os prompts abaixo podem ser vistos em quatro esquemas de cores.

Onde cada configuração fica

Cada camada tem seu arquivo. O script modern-terminal/setup-ghostty.sh escreve todos eles, então uma mudança feita só no arquivo da sua casa some na próxima instalação.

CamadaArquivoComo o setup trataEfeito da mudança
Ghostty~/.config/ghostty/config.ghosttyReescrito a cada execuçãoCtrl+Shift+, recarrega a configuração
Prompt~/.config/starship.tomlReescrito a cada execuçãoImediato, no próximo prompt
zsh~/.zshrcSó o bloco # >>> modern-terminal >>> é reescritoAbra um terminal novo ou rode source ~/.zshrc
Aliases~/.bash_aliasesSó o bloco modern-terminal é reescritoAbra um terminal novo
Para a mudança durar: edite o script modern-terminal/setup-ghostty.sh (seção 3 para zsh e aliases, 4 para Ghostty, 5 para Starship) e rode bash src/modern-terminal.sh. Linhas suas escritas fora do bloco modern-terminal do .zshrc são preservadas. Os backups ficam em *.bak.<data>.
Testar uma configuração do Starship sem instalar nada
STARSHIP_CONFIG=/tmp/teste.toml starship prompt

Como fica na tela

Cada exemplo mostra o resultado de uma configuração, ao lado do trecho para copiar. As saídas do prompt, do eza, do bat e do ripgrep são reais, geradas pelo Starship 1.27 e pelas ferramentas instaladas, e convertidas para HTML no tema Dracula. Ícones como o relógio e o da branch exigem a FiraCode Nerd Font instalada neste computador; sem ela, aparecem como quadrados. Os desenhos do Ghostty e do zsh são simulações em CSS.

Ferramentas instaladas

O que cada uma faz e as opções mais usadas.

eza

ls moderno, com cores, ícones e git.

eza --git -l              # status do git por arquivo
eza -T -L 3               # árvore com 3 níveis
eza -l --sort=modified    # mais recentes por último
eza -l --group-directories-first

bat (batcat)

cat com destaque de sintaxe.

batcat arquivo.py
batcat -A arquivo            # mostra caracteres ocultos
batcat -p arquivo            # sem números de linha
batcat -r 10:30 arquivo.py   # só as linhas 10 a 30
batcat --list-themes

ripgrep (rg)

Busca em arquivos, rápida e respeitando o .gitignore.

rg "texto"
rg -i "texto" src/        # ignora maiúsculas
rg -t sh "sudo"           # só arquivos de shell
rg -l "docker"            # só os nomes dos arquivos
rg -C 2 "erro"            # 2 linhas de contexto
rg --hidden "texto"       # inclui arquivos ocultos

fzf

Filtro interativo para qualquer lista.

git branch | fzf                # escolher uma branch
rg -l "TODO" | fzf              # escolher entre os resultados
vim $(fzf)                      # abrir o arquivo escolhido
fzf --preview "batcat --color=always {}"

micro

Editor de terminal com atalhos comuns.

micro arquivo
# Ctrl+S salvar · Ctrl+Q sair · Ctrl+F buscar
# Ctrl+C / Ctrl+V copiar e colar · Ctrl+Z desfazer
# Ctrl+E abre a barra de comandos, por exemplo: set tabsize 2

As opções ficam em ~/.config/micro/settings.json.
